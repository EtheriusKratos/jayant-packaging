# Jayant Packaging Industries — Premium Website v2

A high-impact, conversion-focused static website.

## Publish on GitHub Pages
Create a GitHub repository, upload all files to its root, then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
